# fullmark

Markdown in, one offline HTML quiz out.

**This branch is fullmark 1.0, a rewrite in TypeScript, in progress.** There is no code yet. The design is in [docs/design/DESIGN.md](docs/design/DESIGN.md) and the command reference in [docs/design/COMMANDS.md](docs/design/COMMANDS.md).

The working version is the Python prototype, fullmark 0.x, on `main` (tag `v0.10.2`). 1.0 is not compatible with it; see [docs/design/fullmark-migration.md](docs/design/fullmark-migration.md) for why.
