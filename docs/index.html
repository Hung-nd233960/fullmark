Fullmark Alchemist

Markdown in, one offline, self-grading HTML quiz out.

Each page below is a single file built by quiz build: no server, no account, nothing loaded from the network. Answers are kept in your browser; Submit grades them and Export answers saves a results file.

Try a quiz

  • Calculus I: derivatives
    Math typeset with KaTeX, numeric answers with tolerances, instant feedback.
  • Rust basics
    Highlighted code, blanks inside code and a code answer, timed, feedback at the end.
  • Cardiac physiology: a medical-science quiz
    Ordering, matching, numeric answers with units and an essay with a rubric.
  • Timed exam: Introductory statistics
    A timed exam: shuffled questions, a random draw from a question bank, a pass mark.
  • IELTS Academic Writing practice
    Two timed writing tasks, exported for AI feedback and a band score.
  • Study habits check-in
    A questionnaire: rating scales, a ranking and open answers, nothing scored.
  • A quiz about fullmark itself
    Nine question types, about this project.
