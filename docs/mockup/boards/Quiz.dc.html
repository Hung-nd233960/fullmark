Fourier transform properties

Property x(t) X(ω)
Linearity a·x(t) + b·y(t) a·X(ω) + b·Y(ω)
Time shift x(t − t₀) e−jωt₀·X(ω)
Frequency shift ejω₀t·x(t) X(ω − ω₀)
Scaling x(at) (1/|a|)·X(ω/a)
Convolution x(t) ∗ y(t) X(ω)·Y(ω)
Multiplication x(t)·y(t) (1/2π)·X(ω) ∗ Y(ω)

Parseval: ∫ |x(t)|² dt = (1/2π) ∫ |X(ω)|² dω

sinc(x) = sin(πx) / (πx), so sinc(0) = 1.

Trigonometric identities

  • ejθ = cos θ + j·sin θ
  • cos θ = (ejθ + e−jθ) / 2
  • sin θ = (ejθ − e−jθ) / 2j
  • cos a·cos b = ½[cos(a − b) + cos(a + b)]
  • sin² θ = (1 − cos 2θ) / 2
