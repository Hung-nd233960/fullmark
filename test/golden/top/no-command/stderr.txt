Usage: quiz [options] [command]

Markdown in, one offline HTML quiz out.

Options:
  --version                      print the version
  --acknowledgements             print fullmark's licence and every third-party
                                 component shipped in the CLI or in its pages
                                 (top level only)
  -h, --help                     help for the command

Commands:
  check [options] <files...>     check quizzes under a profile: syntax errors,
                                 quality warnings, the brief beside the quiz
  rules [options] [rule]         the rule catalogue: what a profile checks and
                                 why a quiz was held to a rule
  ids [options] <files...>       give every question without an id a random one,
                                 and change nothing else
  grade [options] <results...>   re-grade attempts and write a report: score,
                                 wrong answers, and the essays laid out for a
                                 grader
  build [options] [files...]     check a quiz, then write it as one offline HTML
                                 page
  replay [options] <results...>  write an attempt as a page already submitted:
                                 the answers, the explanations and the grades
  inspect [options] <file>       summarise a quiz: question types, points,
                                 sections, tags, banks and where the right
                                 answers sit
  stats [options] <files...>     progress across attempts at one quiz: score by
                                 date, tags, weakest tags, questions missed,
                                 criteria
  new [options] [args...]        start a quiz from a template (quiz template
                                 list) or from an existing quiz
  template                       the templates you start quizzes from: built-in
                                 and your own
  serve [options] <file>         serve a quiz on 127.0.0.1 and write the results
                                 when the learner presses Submit (one submit
                                 only)
  help [command]                 help for a command
