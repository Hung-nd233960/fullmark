## Which number is prime? {type=single id=prime tags=numbers check-ignore="choice.correct-longest" because="the long answer is the point"}

- [ ] Four, which is two times two
- [x] Seven, which has no divisors but one and itself, and so is prime
- [ ] Nine, which is three times three

::: explanation
Seven has no divisors except one and itself, so it is prime. Four and nine are squares.
:::
